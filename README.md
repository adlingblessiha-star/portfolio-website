# Portfolio Website

A personal portfolio built with Flask.

## Features
- Home, Projects, and Contact pages
- Contact form with flash messages
- Responsive layout

## Setup
1. Clone the repo
2. `python -m venv venv`
3. `venv\Scripts\activate`
4. `pip install -r requirements.txt`
5. `python app.py`
6. Open http://127.0.0.1:5000
